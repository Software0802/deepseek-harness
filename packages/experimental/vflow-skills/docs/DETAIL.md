Turn this on and every agent can load the vflow first-mate working rules as a skill.

## How to use

- Ask the agent to act as your first mate, or to push several tasks through the V-model workflow. It loads `vflow-first-mate` and follows its rules.
- The skill appears in the skill list with the other skills; a project or user skill with the same name replaces it.

## Good to know

- The rules ask the agent to delegate changes and to ask you before merges, pushes, and ticket writes. They are instructions, not enforced gates.
- More V-model workflow skills are added in later versions.
